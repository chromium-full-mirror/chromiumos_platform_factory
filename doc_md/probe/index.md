## Overview

The Probe Framework focuses on supplying different ways to scan the device so
that the user can easily figure out whether a specific hardware component is
installed.  The overall introduction is in this [README](https://chromium.googlesource.com/chromiumos/platform/factory/+/HEAD/py/probe/README.md).

This document describes all functions available throughout the Probe Framework.
